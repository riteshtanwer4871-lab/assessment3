# Web Dev I - Lab Assignment 3: Responsive Personal Portfolio Website

**Student Name:** Ritesh  
**Institution:** K.R. Mangalam University  

## Description
This project is an enhanced single-page responsive personal portfolio website built using advanced CSS techniques. It incorporates Flexbox for header and hero alignment, CSS Grid for skills and projects, custom keyframe animations, hover transforms, and responsive media queries to ensure smooth scaling across desktop, tablet, and mobile displays.

## Key Features
- **Flexbox & CSS Grid Layouts:** Managed layout flexibility using modern layout modules without float hacks.
- **Keyframe Animation:** Animated text effect on the "Full Stack Developer" headline.
- **Responsive Design:** Mobile-first media queries to stack elements on screens $\le 768\text{px}$.
- **Relative Units:** Styled layout and typography with `rem`, `vh`, `%`, and `em` relative units.
- **Interactive UI:** Smooth transitions and hover animations on skills cards, project cards, navigation bar, and submit buttons.

## Responsive Breakpoints Tested
- **Desktop:** Above $1024\text{px}$ (Side-by-side hero layout, 3-column skills grid)
- **Tablet:** $768\text{px} - 1024\text{px}$ (Reflowed layout and fluid spacing)
- **Mobile:** Below $768\text{px}$ (Stacked hero text/avatar, single-column flex header, full-width inputs)
